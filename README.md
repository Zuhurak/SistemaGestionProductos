# Sistema de Gestion de Productos

Proyecto final de Programacion III 

## Descripcion

El Sistema de Gestion de Productos permite administrar productos de un inventario mediante una aplicacion web conectada a una API REST.

El sistema permite registrar, consultar, buscar, actualizar y eliminar productos, ademas de controlar el precio, categoria, stock y disponibilidad.

## Tecnologias utilizadas

- Node.js
- Express
- SQLite
- JavaScript
- HTML
- CSS
- Mocha
- Chai
- Supertest

## Funcionalidades

- Registrar productos.
- Consultar productos.
- Buscar productos.
- Consultar productos por ID.
- Actualizar productos.
- Eliminar productos.
- Validar datos.
- Controlar stock.
- Mostrar disponibilidad.
- Pruebas automatizadas.
